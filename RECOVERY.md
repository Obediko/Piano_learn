# Recovery and Troubleshooting Rules

Use this whenever progress stalls. Do not solve every difficulty by watching another video.

## The 10-minute repair rule

If a skill fails the previous day's pass criterion, begin the next session with 10 focused minutes on that skill before new material.

Carry no more than two active repair targets at once.

## Error classification

Before repeating, identify the actual error:

- `NOTE`: wrong pitch/chord
- `FINGERING`: correct notes but inefficient/inconsistent fingers
- `TIMING`: late/early or lost pulse
- `COORDINATION`: hands individually work but fail together
- `MEMORY`: cannot recall what comes next
- `EAR`: cannot hear/find the target
- `TENSION`: physical stiffness or discomfort

One error can require a different solution from another.

## If notes/chords are wrong

1. Stop the metronome.
2. Name every note in the chord.
3. Play the two-chord transition only.
4. Repeat correctly 5 times.
5. Add one chord before and after.
6. Return to slow pulse.

## If fingering is inconsistent

1. Choose one fingering from `TECHNIQUE-MAP.md` or the assigned lesson.
2. Play at half speed.
3. Say finger numbers aloud.
4. Repeat 5 clean times.
5. Do not alternate between fingerings randomly.

## If timing collapses

Use `RHYTHM-TRACK.md` rescue protocol:
- clap;
- count;
- one note/chord;
- 20 bpm slower;
- rebuild layers.

## If hands work separately but not together

1. Reduce left hand to one root note.
2. Play right hand normally.
3. Add left note only on beat 1.
4. Then beats 1/3.
5. Then restore intended left pattern.

Do not practise two-hand chaos repeatedly.

## If memory fails

Use landmarks.

For a song, write only:
- section names;
- first chord of each section;
- number progression;
- one cue for difficult transition.

Then practise starting from the middle. If you can only start from bar 1, the piece is not secure.

## If the ear task fails

Make the contrast easier.
- higher/lower: increase interval size;
- major/minor: use C vs Cm first;
- tonic: use obvious V-I resolution;
- bass movement: reduce to two notes.

Then gradually narrow difficulty.

## If tension/pain appears

Stop speed work immediately.
- shake hands out;
- reset bench distance/height;
- play softly and slowly;
- avoid stretching large intervals repeatedly;
- stop the session if pain persists.

Pain is not a mastery criterion.

## Missed-day policy

One missed day:
- continue next day;
- do not double the session.

Two missed days:
- use next session as 30 min review + 30 min current lesson.

Three or more missed days:
- do a Saturday-style review first;
- identify the last secure skill;
- resume from there;
- do not cram all missed lessons.

## Failed Saturday checkpoint

If weekly score is 70-79:
- continue next week;
- carry one 10-minute repair target.

If score is 60-69:
- continue only the parts of next week that do not depend on the failed skill;
- spend 15 min/day on repair.

If below 60:
- simplify current repertoire to Level 1-2;
- repeat core technical objective for 3 sessions;
- retest before adding advanced decoration.

## Plateau protocol

If the same skill remains stuck for 7 days:
1. reduce tempo by 20%;
2. reduce unit to 2-4 notes or one chord change;
3. check fingering/posture;
4. use exactly one alternate explanation from `VIDEO-LIBRARY.md`;
5. record yourself;
6. compare the recording against the technical criterion, not against a professional performance.

## Overload rule

If you have more than two weak areas in one week, prioritise in this order:
1. pain/tension;
2. pulse/timing;
3. wrong notes/chords;
4. hand coordination;
5. memory;
6. musical decoration.

Fancy chords are never allowed to outrank time and accuracy.
